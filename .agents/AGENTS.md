# Project Rules & Customizations

This file defines project-specific style guidelines, behavioral constraints, and general rules for the Gemini coding assistant in this workspace.

## Coding Style
- Keep backend logic in `backend/app/`.
- Ensure all automated tests pass after any modifications.
- Frontend designs should be responsive and premium.

## Domain Guidelines
- Keep OCR parsing simple and performant. Use selective vision model fallback only for handwritten documents.
